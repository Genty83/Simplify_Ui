# Security Policy

## 1. Purpose

The security of SimplifyUI and its users is important.

This document explains how to report potential security vulnerabilities and how security issues are handled.

## 2. Supported Versions

SimplifyUI is currently under active development.

Security fixes will generally be applied to the latest maintained version. Support arrangements for previous releases will be established as the project matures.

## 3. Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**Do not disclose suspected vulnerabilities through public GitHub issues, pull requests or discussions.**

Use the following private reporting method:

**Security contact:** [INSERT SECURITY CONTACT METHOD]

A dedicated project security email address or GitHub private vulnerability reporting should be configured before public release.

When reporting a vulnerability, include:

- A clear description of the issue.
- The affected package, application or component.
- Steps to reproduce the vulnerability, where possible.
- The potential security impact.
- Any suggested mitigation or supporting evidence.

Please avoid including personal information, credentials or other sensitive data unless strictly necessary.

## 4. Handling Security Reports

Security reports will be reviewed and investigated by the project maintainer.

Where a vulnerability is confirmed, appropriate action may include:

- Assessing the severity and potential impact.
- Developing and testing a fix.
- Releasing an updated version.
- Publishing relevant security advisories.
- Providing mitigation guidance where an immediate fix is not available.

Response and resolution times are not currently guaranteed.

## 5. Responsible Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before making technical details public.

The project aims to handle security reports responsibly and communicate relevant updates where appropriate.

## 6. Scope

This policy covers security vulnerabilities affecting SimplifyUI repositories, packages, applications and associated project infrastructure.

Third-party dependencies and services may have their own security reporting processes. Where appropriate, vulnerabilities should also be reported to the relevant maintainers.
